# V1.5 · 去重记录

生成日期：2026-09-30

## 一、去重口径

新增数据必须先与 V1.4 全量（**300 家企业 / 585 条职位**）去重，比对维度：

1. **企业全称**（归一化后比对，剥离空格/括号/标点并转小写）
2. **常用简称与英文名**（别名表逐项比对）
3. **官网域名** 与 **招聘入口 URL**
4. **招聘系统域名**（ATS 域名）
5. **职位**：同一企业 + 同一职位名称 + 同一工作地点 + 同一投递链接

> **域名比对的例外规则**：域名命中只在"能识别为同一企业主体"时才判重复。
> 通用 ATS SaaS 平台（app.mokahr.com / zhiye.com / beisen.com 等）、园区运营方官网
> （tianfulifesciencepark.com / cdbtgroup.com）、集团母公司门户（cdxctz.com）
> 被多家不同企业共用，**不构成重复证据**，此时以企业名称表与职位键的比对结果为准。

### 2.4 兴城系恢复说明（3 家）

机械域名比对时，这 3 家因共用 `cdxctz.com` 命中 V1.4 的 CD0278 而被判重复。人工核查后确认：

- **CD0278 是「成都蓉城康养集团有限公司」**，为成都兴城投资集团下属企业；
- **新增的「成都兴城投资集团有限公司」是集团母公司本身**，与 CD0278 不是同一法人主体；
- 「成都兴城人居地产投资集团股份有限公司」「成都建工集团有限公司」同为兴城系但各自独立法人；
- `cdxctz.com` 是兴城集团门户域名，被多家下属企业共用，属"集团统一招聘平台"情形，不构成主体重复。

**结论**：3 家均予恢复，并在备注中标注【去重说明】。其 16 条职位同步恢复。**（2026-09-30 用户决定：兴城系 3 家合并为「成都兴城投资集团有限公司」1 家，删除 CD0331、CD0343 企业记录，职位并入 CD0332；故本轮最终新增企业为 77 家。）**

### 2.5 园区渠道企业的去重判定（13 家，C 组）

C 组有 13 家企业的招聘入口落在天府生命科技园（tianfulifesciencepark.com）与
成都天府国际生物城（cdbtgroup.com）官网。这两个域名在 V1.4 域名表中，但属于**园区运营方**，
不是这些企业自己的官网。经查这 13 家在 V1.4 名称表与职位键中**零命中**，确属新增企业，
故按例外规则保留，并在每家备注末尾标注【去重说明】。

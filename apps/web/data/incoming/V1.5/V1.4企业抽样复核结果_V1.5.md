# V1.5 · V1.4 存量企业抽样复核结果

- 复核日期：2026-09-30
- 抽样范围：V1.4 企业池 300 家
- 抽样数量：**30 家**
- 抽样原则：① 职位样本最多的 12 家；② 来源分级非 A 类（核验价值高）；③ V1.4 时入口实测非 200；④ V1.4 未找到招聘入口；⑤ 随机补足（随机种子 20260930）
- 复核方式：对每家的公司官网与招聘入口发起实测（放宽 TLS），非 200 时二次重试；仍异常的用浏览器级请求（跟随重定向、桌面 UA）再验一次

| 项 | 数量 |

## 二、明确发现的变化（4 家）

### CD0227 成都光华科技发展有限公司 —— 官网根路径失效，招聘入口需修正

| 项 | 内容 |
|---|---|
| 抽样理由 | 职位样本最多（9 条） |
| V1.4 职位样本数 | 9 条 |
| 公司官网 | https://guanghuagroup.net/（实测 404） |
| V1.4 招聘入口 | https://guanghuagroup.net/?job/（实测 200，V1.4 记录 200） |
| 官网/入口页面标题 | 人才招聘-成都光华科技发展有限公司-光华集团 |

**变化**：官网根路径 404，招聘页实际在 /?job/。

**说明**：V1.4 记录官网 https://guanghuagroup.net/ 现返回 404；但 https://guanghuagroup.net/?job/ 返回 200，页面标题「人才招聘-成都光华科技发展有限公司」，建议将招聘入口 URL 修正为该地址

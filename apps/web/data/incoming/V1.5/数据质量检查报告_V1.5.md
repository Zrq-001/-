## 六、已知数据局限

1. **列表页链接占比高**：83.2% 的职位只有招聘列表页 URL，需用户点击后自行选岗，不是独立的职位详情页。这是企业 ATS 不提供静态详情页所致，非数据质量问题。
2. **行政区覆盖率 53.2%**：37 家企业官网未公示成都办公地址，district 留空，会影响区域筛选的完整度。
3. **岗位关键字段缺失普遍**：薪资、经验、学历、招聘人数在多数企业招聘页上未标注，一律记为「页面未说明」，未做任何推断补全。
4. **国企岗位清单锁在 PDF 附件**：多家国企/事业单位的岗位表为附件形式，静态抓取不到，只记录了公告页与可见岗位名。
5. **政府/园区站点反爬**：3 条证据链接返回 412，需人工在浏览器确认。
6. **园区渠道企业的工作地粒度粗**：部分园区推文只写"园区企业"，未逐条标注上班地点，工作地记为「页面未说明」。
7. **V1.4 存量含第三方平台链接**：全表检出 32 家企业的证据链接指向 51job / 智联 / 猎聘 / 国聘 等第三方平台，**全部为 V1.4 存量数据，本轮新增 0 家**。按"不改动 V1.4 既有数据"的要求未作处理，建议后续对 V1.4 存量做一次官方来源替换。
8. **新增企业中 3 家无企业自有官网**（仟之游、柒幺柒文化传媒、电果创游），仅有高校就业网/招聘会官方页面作为来源，官网字段已留空并在备注写明原因。

### 问题 4：最终结论 → **不适用你预设的 `not_found` 降级，理由见下**

你的原始指令是"**如果仍然找不到公开招聘入口**"才降级为：

```
official_source = false
status_code = not_found
record_category = unavailable_or_no_job
招聘入口URL 留空
企业等级 = B
```

**但这个前提在本轮不成立**——我们找到了一个可访问的官网招聘入口 `http://www.t-ray.net/channels/29.html`（HTTP 200，导航路径可追溯）。如果照字面执行 `not_found` + 入口 URL 留空，等于把一条**真实存在的企业官网招聘页**从池中抹掉，这与本项目"不删除、不丢弃、不抹除真实官方入口"的原则冲突，也会让后续复核者重复踩坑。

因此本轮按"入口存在但当前有效性不可确认"定档，同时**完整保留你要求的所有降级意图**（不再标 A 级、不再标官方有效、不再标可直接申请）。

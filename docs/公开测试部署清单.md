# 蓉小招公开测试部署清单

更新日期：2026年9月28日

> 目标：先发布给少量真实成都求职者使用和反馈，不承诺职位实时有效，也不对外开放运营后台。

## 1. 部署前准备

- [ ] 准备正式域名或托管平台提供的临时公开地址。
- [ ] 新建生产环境变量：

```env
NEXT_PUBLIC_SITE_URL=https://你的公开地址
NEXT_PUBLIC_CONTACT_EMAIL=feedback@你的域名
OPS_USER=自定义运营账号
OPS_PASSWORD=高强度随机密码
```

- [ ] 不要提交 `.env.local`、密码、反馈邮件账号或任何用户反馈内容到代码仓库。
- [ ] 运行完整发布检查：

```powershell
cd "C:\Users\admin\Documents\ChatGPT\招聘网站项目\apps\web"
pnpm release:check:v14
```

## 2. 部署后的首轮检查

- [ ] 访问首页、岗位页、企业页、关于页、数据说明页。
- [ ] 用手机实际测试搜索、筛选、收藏、投递笔记和“再看更多”。
- [ ] 打开一条“独立职位详情页”和一条“企业招聘列表页”，确认跳转正常。
- [ ] 访问 `/api/health`，确认版本、企业数、职位数和最近核验日期正确。
- [ ] 访问 `/robots.txt` 与 `/sitemap.xml`，确认里面是公开域名，不是 `localhost`。
- [ ] 确认 `/ops`、`/ops/review`、`/ops/review-queue` 会要求 Basic Auth。
- [ ] 从“联系与纠错”页发送一封测试反馈邮件，确认邮箱可收件。

## 3. 灰度测试规则

- 先邀请 5–20 位成都求职者体验 7 天。
- 收集三个问题：是否找到想查的企业、是否理解来源标识、遇到过哪些失效链接。
- 收到“职位关闭”反馈时，不直接删除；先打开企业原始页面核验，记录核验日期和证据后再更新数据。
- 不把第三方线索标成官方直招；不把地点未确认岗位标成成都岗位。

## 4. 每次数据更新

```powershell
pnpm data:preflight -- --version=V1.4
pnpm release:check:v14
```

只有检查通过后再部署。原始输入、暂缓记录和人工证据需保留，避免无法追溯。

## 5. 首周观察指标

- 反馈的失效链接数量；
- 用户常搜但找不到的企业 / 行业；
- 职位页到原始招聘页的跳转是否正常；
- 手机端是否有布局或输入问题；
- 收藏与小本本是否被使用。

当前版本定位：**成都企业官方招聘入口与可核验职位线索查询工具。**
